CURRENT SYSTEM FUNCTIONS (MOBILE + WEB)

MOBILE APP (CLIENT) - DB-TIED FEATURES WORKING
1) Auth
- Register customer via /api/auth.php (users)
- Login customer via /api/auth.php (users/staff_users/barbers)

2) AI Face Scan + Hair Recommender
- Upload image to /api/ai_scan.php (multipart)
- CV pipeline runs (MediaPipe) and returns hair attributes
- Optional Gemini analysis for face + hair attributes
- Pulls hairstyle variants from DB (hairstyles + hairstyle_variants)
- Returns up to 8 ranked recommendations + AI summary

3) Hairstyle Library
- listLibrary via /api/haircuts.php (hairstyles + top variant)
- Detail page uses front/side/back URLs from DB
- Library filters by hair texture folders (Straight/Wavy/Curly/Coily/Mixed)

4) Barbers & Services
- List barbers via /api/barbers.php (barbers)
- List services via /api/services.php (services)
- List time slots via /api/time_slots.php (time_slots)

5) Favorites / Bookmarks
- Save or remove haircut variants via /api/favorites.php (add/remove/status)
- List favorites via /api/favorites.php (listByUser)
- Saved Haircuts page pulls from user_favorites
