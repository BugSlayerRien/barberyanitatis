
AI HAIRSTYLE RECOMMENDER – SIMPLE PLAN (NO COMPLEXITY)

GOAL
- After scan, show a preview of the haircut (front + side) and top 5 recommendations.
- If the user dislikes all 5, only then let them pick from the library/assets.

SIMPLE FLOW (MVP)
1) Scan photo (mobile camera or upload).
2) POST /api/ai_scan.php (multipart).
3) Backend detects face shape + hair texture.
4) Query hairstyle_variants (face_shape + hair_texture) and return top 5.
5) UI shows:
   - Preview tabs: Front / Side / Back
   - Top 5 list (tap to preview another)
6) If user taps “Choose from library”, show full list from /api/haircuts.php and use assets.

TRY-ON WITHOUT COMPLEXITY
- Use pre-generated images in hairstyle_variants (front/side/back).
- No real-time image generation needed.
- Just show the stored images as “preview”.

API MINIMUM
- POST /api/ai_scan.php -> returns top 5 variants with front/side/back URLs.
- POST /api/haircuts.php (action=listByFaceShape or list) -> returns library variants.

ONLY USE LIBRARY WHEN:
- No recommendations returned, or
- User presses “Choose from library”.

NEXT STEPS
- Seed more variants (front/side/back) in hairstyle_variants.
- Ensure PUBLIC_BASE_URL so images resolve in web/mobile.
