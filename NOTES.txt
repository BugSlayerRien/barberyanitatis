SIGN IN / SIGN UP PROCESS (MOBILE + WEB)

MOBILE (Flutter)
- Screen: AuthPage
- API endpoint: /api/auth.php
- Sign Up (register)
   - Sends JSON: action=register, fullName, email, password, phone, roleName=Customer
   - API hashes password with bcrypt and inserts into users
   - On success: shows “Registration successful”, then switches to login
- Sign In (login)
   - Sends JSON: action=login, email, password
   - API checks users, staff_users, and barbers (in that order)
   - Returns roles: customer / admin / receptionist / barber
   - App routes based on role

WEB (Admin/Receptionist)
- Page: /web-admin/login.html
- Script: /web-admin/login.js
- API endpoint: /api/auth.php
- On success: roles are read; redirects to /web-admin/admin or /web-admin/receptionist
