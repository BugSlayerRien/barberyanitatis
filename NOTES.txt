Firebase setup notes (configure later):
1) Run FlutterFire CLI to generate firebase_options.dart.
	- flutterfire configure
2) Add google-services.json (Android) in android/app/ and GoogleService-Info.plist (iOS) in ios/Runner/.
3) Enable Email/Password + Google providers in Firebase Auth.
4) For Android: add SHA-1/SHA-256 to Firebase console.
5) For Web: add web config in firebase_options.dart.
6) After setup, run: flutter pub get
