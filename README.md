# Barbershop Management System

A comprehensive AI-powered barbershop management system for streamlining operations, appointments, and customer service.

## Project Overview

This is a capstone project for the Bachelor of Science in Information Technology, featuring an intelligent barbershop management platform with AI-powered hairstyle recommendations.

## Platforms

- **Mobile App (Flutter)** – Customer-facing application for bookings and recommendations
- **Web Application** – Admin and receptionist dashboard for management
- **Backend API** – MySQL-based REST API for data management

## Core Features

### 1. AI-Powered Hairstyle Recommendation
- Computer vision-based face shape analysis
- Personalized hairstyle suggestions
- Feasibility checks based on hair type and face structure
- Before/after visualization

### 2. Smart Appointment Scheduling
- Real-time availability checking
- Automated booking confirmations
- Calendar integration
- Reminder notifications
- Queue management

### 3. Stylist and Service Management
- Stylist profiles and specializations
- Service catalog with pricing
- Performance tracking
- Schedule management

### 4. Analytics and Reporting
- Business performance metrics
- Customer insights
- Revenue tracking
- Popular services analysis
- Stylist performance reports

## Tech Stack

- **Frontend (Mobile)**: Flutter
- **Frontend (Web)**: HTML/CSS/JavaScript (React/Vue.js recommended)
- **Backend**: Node.js/Python with REST API
- **Database**: MySQL
- **AI/ML**: TensorFlow/PyTorch for computer vision
- **Cloud Services**: AWS/Google Cloud for hosting
