CURRENT DATABASE REMINDERS (LATEST SCHEMA)

SYSTEM RULES (DON'T BREAK THESE)
1) All apps (mobile, web) use PHP API only.
2) Flutter/web NEVER access MySQL directly.
3) Keep data normalized; avoid duplicates.
4) Use snake_case column names as defined in /database/schema.sql.

CORE TABLE PURPOSES (LATEST)
1) USER MANAGEMENT
- users: registered customers (mobile app). Login + profile info + status.
- user_profiles: AI-detected attributes for recommendations.
- staff_users: admin/receptionist accounts for web dashboards.

2) BARBER MANAGEMENT
- barbers: barber credentials, profiles, specialties, ratings.

3) HAIRSTYLE CATALOG (AI DATASET)
- hairstyles: master catalog (metadata).
- hairstyle_variants: AI-ready images per face shape/hair texture + barber instructions.

4) SERVICES & PRICING
- services: menu with base_duration/base_price + category.

5) AI SCAN
- Uses /api/ai_scan.php and returns ranked recommendations directly.

6) APPOINTMENTS (MOBILE)
- appointments: future bookings with booking_code and time range.
- appointment_details: linked services + chosen hairstyle variant.

7) TIME SLOT MANAGEMENT
- time_slots: 35-minute slots linked to appointments.

8) WALK-IN QUEUE
- walkin_queue: live queue + status.
- walkin_service_details: services + variant chosen for walk-ins.

9) PAYMENTS
- payments: unified payments for appointments or walk-ins.

10) FEEDBACK
- feedback: detailed ratings by category.

11) NOTIFICATIONS
- notifications: unified notifications for users/barbers/admin.

12) USER PREFERENCES & HISTORY
- user_favorites: saved variants/barbers.
- user_history: historical haircut/service records.

13) ANALYTICS & REPORTS
- daily_analytics, barber_performance: metrics.

14) SYSTEM MANAGEMENT
- system_settings, audit_logs: system configs + audit trail.

15) DISPLAY VIEW
- queue_display: merged appointment + walk-in queue view.

AI HAIRSTYLE SCANNER FLOW
1) Mobile/web captures image and posts to /api/ai_scan.php (multipart/form-data).
2) Backend analyzes face/hair and ranks hairstyle_variants.
3) Returns recommendations + summary to client.

TABLES USED BY AI SCAN
- hairstyle_variants
- hairstyles

DATA CONSISTENCY NOTES
- payments must link to appointment_id or queue_id (one required).
- appointment_details.variant_id is required.
- walkin_service_details.variant_id is required.
